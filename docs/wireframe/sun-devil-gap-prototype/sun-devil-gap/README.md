# Sun Devil Gap — ASU Gap Time Map front-end concept

ASU-themed, interactive front-end prototype for the team's October 28 proposal. Created by Cade Garner, Schedule Input and Front-End Lead.

## Two wireframes
1. **Plan your gap:** current location, next class building, class start time, date, and an illustrative available-time input.
2. **Explore campus:** activity categories, minimum visit duration, future date, illustrative campus layout, and sample result cards.

## Run locally
Open `index.html` with VS Code Live Server, or open it directly in a browser. No build tools are required.

## Publish over HTTPS
1. Add `index.html`, `style.css`, and `js/app.js` to a repository (preferably in a `docs/` folder or at the repository root).
2. Push your work to GitHub


## Limitations
- The map is an illustrative drawing, not a real basemap.
- Results are sample cards, not live ASU events or verified places.
- Routing, walking times, event matching, and schedule feasibility are not yet implemented.
- The time slider represents a manually entered available-time estimate; the class time is not used to calculate that duration yet.
